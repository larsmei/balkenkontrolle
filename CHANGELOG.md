# Changelog

## 1.1.8 — 2026-11-07

* The Beams button uses the I-beam icon.
* The plugin, including the dialog, messages, and this documentation, is in English.

## 1.1.7 — 2026-11-07

* The Beams toggle is placed on the AsterStudy menu bar.

* `SECTION='GENERALE'` is drawn as a solid ellipse with the given `IY` and `IZ`.

* The toggle is installed once. Edge groups on an SMESH mesh are read even when the SALOME 9 element-type comparison fails.

## 1.1.4 — 2026-11-07

* First toolbar toggle for the beams of the active study.

## 1.0.0 — 2026-11-07

* First release: local axes and cross-sections from `AFFE_CARA_ELEM` in the AsterStudy view.
